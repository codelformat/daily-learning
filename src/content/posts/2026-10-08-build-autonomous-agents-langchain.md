## 为什么这门课重要

- 从"知道 Agent"到"搭出 Agent"，这是求职叙事里最关键的一跃——面试官问的永远是"你做过什么"，不是"你学过什么"；
- LangChain 是 Agent 岗的通用语言，哪怕以后换框架，这套心智模型（tool / memory / planning loop）都复用；
- 跟 MCP 的课是互补的：这门讲"Agent 怎么转起来"，MCP 讲"Agent 怎么接外部世界"。
